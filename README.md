# Sleep Pause Timer

Плагин [Astra](https://github.com/mihailinl/AstraPlugins) от **Voltur** (лицензия MIT) —
портирование автономной программы «Таймер паузы» (`sleep_pause.py`).

## Что умеет

- **Обратный отсчёт** с паузой, продолжением и отменой — управляется голосом
  или текстом через Астру.
- **Действие по завершении** (как в оригинальной программе):
  - `playpause` — нажать медиа-клавишу play/pause (пауза видео/музыки);
  - `shutdown` — выключить ПК;
  - `sleep` — усыпить ПК.
- **Активация окна** перед нажатием клавиши: по подстроке заголовка или по
  номеру `#N` из списка окон (поддержка Chromium-браузеров — Яндекс.Браузер,
  Chrome, Edge — как в оригинале).
- **Виджет на главном экране** Astra (слот `home.widgets`): отсчёт, прогресс,
  кнопки «пауза/продолжить» и «отмена». Прозрачный, следует теме Astra.

## Инструменты для Астры

| Инструмент | Что делает |
|---|---|
| `start_timer` | Запустить отсчёт: `hours`, `minutes`, `seconds`, `action`, `window` |
| `pause_timer` | Пауза |
| `resume_timer` | Продолжить |
| `cancel_timer` | Отменить (действие не выполняется) |
| `timer_status` | Сколько осталось и что будет по завершении |
| `list_windows` | Нумерованный список открытых окон для выбора цели |

Примеры: *«поставь таймер на 5 минут, потом нажми play в YouTube»*,
*«таймер на полчаса и выключи компьютер»*, *«сколько осталось?»*.

## Настройки

В настройках плагина (Астра рисует форму сама): действие по умолчанию и окно
по умолчанию — тогда `start_timer` можно звать без этих аргументов.

## Разрешения

Плагин **не запрашивает ни одного разрешения**: виджет сам опрашивает плагин,
инструменты вызывает Астра, наружные вызовы демону не нужны.

## Установка (режим разработчика)

1. В Astra: **Settings → Privacy** → включить **«Allow unsigned plugins»**.
2. **Plugins → Dev** → вставить путь к папке в поле **«Load a plugin»** → нажать загрузку.
3. После перезапуска Astra плагин из папки возвращается **выключенным** —
   включите его во вкладке Installed.

Собственное виртуальное окружение (`.venv`) лежит внутри папки плагина —
системный Python не используется.

## Отличия от оригинальной программы

- Не нужны pyautogui/pygetwindow/win32gui/pystray — всё на чистом `ctypes`.
- Исправлен спящий режим: `SetSuspendState` вызывается из `PowrProf.dll`
  (в оригинале вызов через `kernel32` падал с `AttributeError`).
- GUI на Tkinter заменён виджетом в окне Astra; трей не нужен — управляет Астра.
