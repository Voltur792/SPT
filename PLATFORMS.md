# Поддержка платформ

**Windows — основная платформа. Linux и macOS — экспериментальная поддержка.**

Полная ручная проверка на Linux и macOS ещё не выполнена. Автоматические проверки на Windows, Ubuntu и macOS доступны во вкладке Actions, workflow «Platform checks». Они проверяют зависимости и программную логику, но не заменяют проверку микрофона, звука, окон, системных разрешений и аккаунтов в обычном графическом сеансе.

Astra выпускает хосты плагинов для Windows x64 и Linux x64. macOS и ARM пока зарезервированы без выпускаемого хоста: наличие кода macOS не означает, что плагин уже можно установить в Astra на Mac. См. [официальный список платформ](https://github.com/mihailinl/AstraPlugins/blob/master/astra-plugin-cli/vendor/astra-plugin-manifest/src/platform.rs).

Данные Windows сохраняются в прежних папках. В Linux используются стандартные XDG-папки пользователя, в macOS — `~/Library/Application Support`. Перенос личных ключей и аккаунтов между ОС не выполняется автоматически. `ASTRA_CONFIG_DIR` позволяет указать нестандартную папку конфигурации Astra.

Для собственных настольных окон на Linux нужны зависимости `pywebview[qt]`, а в сеансе Wayland — также Qt Wayland platform plugin. Пользовательские `QT_QPA_PLATFORM` и `PYWEBVIEW_GUI` сохраняются. Работа поверх всех окон и расположение зависят от композитора. Изменения относятся к окнам плагинов; общий оверлей Astra обновляется отдельно разработчиком Astra.

## Таймер паузы

Обычные таймеры, будильники, расписание радио и интеграции работают через переносимую логику. Linux: системные питание/сон через systemctl, музыка через playerctl (MPRIS), звук будильника через ffplay. macOS: pmset, System Events, afplay; пауза для запущенного Spotify или Music.

X11: список/активация окон через wmctrl, сочетания клавиш через xdotool, бездействие через xprintidle. Wayland: окна Sway/Hyprland через их собственный IPC, клавиши через wtype при поддержке virtual-keyboard. GNOME/KDE не дают универсальный список чужих окон. Обычный таймер не зависит от этих функций.

Бездействие: macOS HIDIdleTime, X11 xprintidle. В Wayland функция бездействия пока сообщает о недоступности; обычный отсчёт продолжает работать. KDE GetSessionIdleTime прямо возвращает NotSupported на Wayland: https://github.com/KDE/kscreenlocker/blob/master/interface.cpp. Неполные данные не используются для автоматического выключения.

Снимки: Windows прежний API; macOS/X11 Pillow с системным разрешением, Wayland grim при поддержке screencopy композитором. В GNOME/KDE универсальный фоновый захват не обещается; для Discord доступен отдельный браузерный выбор экрана. Нельзя переносить сохранённый ID монитора Windows — выберите экран заново.

Qt-виджеты не требуют X11; положение и оформление окна определяет композитор. В macOS нужно разрешение Automation/Accessibility для управления окнами и запись экрана для снимков.
